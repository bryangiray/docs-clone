# Submission

What is in this repository, and what is deliberately not. Setup instructions are in [README.md](README.md); how AI was used is in [AI_WORKFLOW.md](AI_WORKFLOW.md).

## At a glance

| | |
| --- | --- |
| App | Docs Clone, a Google Docs–style document editor |
| Stack | Next.js 16 (App Router, Server Actions), React 19, Tiptap 3, Tailwind CSS 4, PostgreSQL, pdfmake |
| Repository | `git@github.com:bryangiray/docs-clone.git` |

## Features included

### Core application

- **Sign-in** by username, with a 30-day session cookie.
- **Dashboard** listing "Owned by me" and "Shared with me", with who last changed each document and when.
- **Create** a blank document, or **import** a `.txt`, `.md` or `.docx` file (up to 10 MB). Markdown and Word files keep their formatting.
- **Rich-text editor**: headings 1–3, bold, italic, underline, bulleted and numbered lists, undo and redo.
- **Saving**: autosave shortly after each change, a Save button, Cmd/Ctrl+S, and a warning before leaving with unsaved edits.
- **Rename** and **delete** (delete is owner-only and also removes the uploaded original).
- **Sharing** with other users as editor, commenter or viewer; the owner can change or remove access.
- **Activity log** per document: created, viewed, edited, renamed, restored.
- **Admin page** (`/admin`): add users and set which file extensions can be uploaded.

### Enhancements

- **Real-time collaboration indicators.** Avatars of everyone else who has the document open, with a green ring and an "is editing…" label while they type. Updates within about four seconds.
- **Commenting.** Comment on selected text or on the whole document, reply in threads, resolve and reopen, delete. Commented text is highlighted in the document, and clicking it opens the thread. Other people's comments appear without a reload.
- **Document version history.** A list of earlier versions, a read-only preview of each, and one-click restore. Restoring adds a new version, so it can be undone.
- **Export to PDF.** Downloads the document as a PDF with selectable text, keeping headings, lists, quotes, code blocks and links.

`users`, `documents`, `document_shares`, `document_activity`, `document_versions`, `document_comments`, `document_presence`, `document_attachments`, `global_settings`.

### Tests

| Area | Covers |

## Not included

- **Suggestion mode.** The brief offered commenting or suggestion mode; commenting was built.
- **Live merging of text.** Presence shows who is editing, but two people typing at once are not merged: the last save wins.
- **Passwords and access control on `/admin`.** Sign-in is by username only and the admin page is open. This is a demo, not something to expose to the internet; see "Security notes" in the README.
- **End-to-end and database tests.** The browser flows were checked once with a throwaway script (described in `AI_WORKFLOW.md`), which is not in the repository. No test runs real SQL.
- **File attachments.** The `document_attachments` table exists but nothing uses it yet.
- **Non-Latin text in PDFs.** The export font covers Latin, Cyrillic and Greek only.
- **A confirmed live deployment.** The CI/CD pipeline targets `http://159.65.12.97:3001`, but when this file was written the server and the GitHub secrets had not been set up, so the pipeline had not yet deployed. Setup steps are in the README under "Deployment (CI/CD)".
- **Local-only files.** `.env.local`, `uploads/`, `node_modules/` and build output are git-ignored. Seed data contains users only, no documents.
